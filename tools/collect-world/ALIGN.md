# 수능특강(2027) 기준 맞추기 — 수집할 자료, 출처별

기준은 Promenade 통계 사이트 화면(2026-10-22 출력, 인구·도시·식량·에너지·산업·교통과 무역·지역 7개 페이지)에 적힌 출처와 연도다.
**먼저 정리한 "2023 기준"은 빌드 스크립트의 교재 기준값이었고, 실제 사이트는 대부분 2024~2025다.**
종교·기후 페이지는 아직 안 봤다.
