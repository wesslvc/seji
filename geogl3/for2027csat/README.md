# Geogl3 — 2027 수능 대비판 (보관)

2026년 11월 수능이 끝나 보관한 판이다. 주소: `geogl3.xyz/geogl3/for2027csat/`
새 첫 화면(`geogl3.xyz/`)은 여행 동선 서비스이고, 이 폴더는 그와 따로 돌아간다.

## 한 사이트로 묶인 구성

| 경로 | 내용 |
|---|---|
| `./` | 본편 — 나라·접경국·종교·무역·에너지·하천·기후·도시 퀴즈, 한국지리, 수특 퀴즈, 세지 위키 |
| `abyss/` | Abyss — 세계지리 원자료 자료실(아틀라스·순위 도감·통계 테스트·기후 카드·지엽개념) |
| `earth/` | Earth — 지구과학 개념 퀴즈 |
| `f1/` | F1 — 서킷 기후 그래프 |
| `data/archive/` | 보관 기록(아래) |

- 본편과 Abyss는 **같은 자료를 한 벌만** 쓴다. 국기(`flags/`), 기후·하천·기후지도 자료, 새 그림, 디자인 토큰은
  본편 것을 Abyss가 `../` 로 불러 쓴다. Abyss 폴더에는 Abyss에만 있는 화면·자료만 남겼다.
  (`abyss/js/data.js`·`dict-data.js`·`city-data.js` 는 Abyss용으로 갈라진 판이라 따로 둔다.)
- 오가는 길: 본편 첫 화면의 **Abyss 카드**, Abyss 첫 화면의 **← 퀴즈 본편** 링크.
  예전처럼 본편 맨 아래에서 세 번 더 내려가면 가라앉고, Abyss 맨 위에서 세 번 더 올라가면 떠오른다.

## 보관 모드

- 로그인(구글, Supabase Auth)은 그대로다. 로그인하면 그동안의 기록을 본다.
- 점수 제출·위키 편집·댓글·계정 동기화는 닫았다. 계속 플레이할 수 있지만 점수는 오르지 않는다.
- 기록은 `data/archive/` 의 고정 파일에서 읽는다(`js/archive.js` 가 본편·Abyss·Earth 공용으로 읽는다).
  - `public.json` — 랭킹·위키(설명·이력·댓글·조회수). 사람 구분은 가명(pid). 프로필 사진은 `avatars/` 로 옮김.
  - `records.json` — 사람별 기록(프로필·점수·Abyss 오답/즐겨찾기·Earth 오답). 사람마다 AES-GCM 암호문이고,
    구글로 로그인한 본인의 사용자 id로만 열린다. 이메일은 어디에도 담지 않았다.
- 2026-11-20 기준 Supabase에서 내보냈다: 유저 140명, 점수 679건, 위키 설명 241개·이력 551건·댓글 52개.
